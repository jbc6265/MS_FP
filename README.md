# 명성공업 서열정보&소요자재 자동 취합 프로그램

현대건설기계 HI-SRM에서 내려받은 월확정조립서열계획 파일과 물류번호별 소요자재현황 파일을 `생산번호 = 물류번호` 기준으로 병합하는 Windows GUI 프로그램입니다.

## 우선 실행: CMD 파일

Python이 설치된 PC에서는 아래 CMD 파일을 먼저 사용합니다.

```bat
명성공업_서열정보_소요자재_자동취합.cmd
```

이 CMD 파일은 필요한 Python 패키지를 확인한 뒤 `app.py`를 실행합니다.

## 나중에 EXE 생성

배포용 EXE는 아래 파일로 생성합니다.

```bat
build_exe.bat
```

생성 위치:

```text
dist\Myeongseong_Sequence_Material_Merge.exe
```

## 사용 순서

1. 월확정서열 파일 4종 중 1개 이상을 선택합니다.
2. 물류번호별 자재소요현황 파일을 선택합니다.
3. 각 파일 영역에서 출력할 컬럼을 검색하고 복수 선택합니다.
4. 저장 폴더를 지정합니다.
5. `병합 엑셀 생성` 버튼을 누릅니다.

## 출력 파일

파일명은 `서열_자재_통합_YYYYMMDD_HHMMSS.xlsx` 형식으로 자동 생성됩니다.

생성 시트:

- `정상병합`
- `월확정_미매칭`
- `자재_미매칭`
- `실행요약`

## 주의사항

- 월확정 파일에는 `생산번호` 컬럼이 있어야 합니다.
- 자재소요현황 파일에는 `물류번호` 컬럼이 있어야 합니다.
- 동일 파일을 두 입력 영역에 중복 선택할 수 없습니다.
- 기본 선택 컬럼은 아직 지정하지 않았으므로, 업로드 후 필요한 컬럼을 직접 선택해야 합니다.
